# Sistema de Gestão de Monitorias — Banco de Dados

Projeto acadêmico desenvolvido na disciplina de Banco de Dados I, na Universidade do Estado do Rio de Janeiro (UERJ).

## Sobre o projeto

O projeto consiste na modelagem e implementação de um banco de dados para um sistema de gestão de monitorias universitárias.

O sistema tem como objetivo organizar informações sobre alunos, professores, disciplinas, monitores e sessões de monitoria, permitindo o gerenciamento de inscrições e registros de presença.

## Tecnologias utilizadas

- PostgreSQL
- SQL

## Desenvolvimento

O projeto contempla as seguintes etapas:

- Modelagem conceitual utilizando Diagrama Entidade-Relacionamento (DER).
- Mapeamento do modelo conceitual para o modelo relacional.
- Normalização das tabelas até a Terceira Forma Normal (3FN).
- Identificação de dependências funcionais.
- Definição de chaves primárias, estrangeiras e restrições de integridade.
- Implementação do banco de dados utilizando PostgreSQL.
- Inserção de dados e elaboração de consultas SQL.
- Testes de integridade referencial e operações de manipulação de dados.

## Consultas SQL

Foram desenvolvidas consultas utilizando:

- SELECT e WHERE
- JOIN
- GROUP BY e HAVING
- COUNT
- INSERT, UPDATE e DELETE
